# fonts

Bundled fonts, stowed into `~/Library/Fonts`.

## Google Sans Code

- `GoogleSansCode[wght].ttf` — Roman variable font
- `GoogleSansCode-Italic[wght].ttf` — Italic variable font

Google Sans Code is an **open-source** typeface (not the proprietary "Google
Sans" brand font). Licensed under the **SIL Open Font License 1.1** — free to
use, modify, and redistribute. The license text is in [`OFL.txt`](Library/Fonts/OFL.txt),
included here as the OFL requires it to accompany the font files.

Source: https://github.com/googlefonts/googlesans-code
